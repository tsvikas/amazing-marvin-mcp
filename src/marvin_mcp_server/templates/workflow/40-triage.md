## Inbox triage checklist

When I say "let's go over the inbox", do this for each item, one at a time,
and ask me only when something is unclear:

1. Rephrase the title as a clear, actionable next step (or turn it into a
   project with a first action).
1. Set an energy label.
1. Set a duration estimate.
1. Move it to a category / project.
1. Add context labels (location, requirements, waiting-for).
1. Give it a do date (or leave it unscheduled on purpose) and a due date only
   if the deadline is real.
